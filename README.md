# DeshiLens (দেশি লেন্স) — curated research edition

A mobile-first, Bangla-first archive prototype for Bangladeshi internet culture.

## Run / publish
Open `index.html` in a browser. To host it, upload `index.html` and the complete `assets/` folder to a static website host (Netlify, GitHub Pages, or similar). Do not upload only the HTML file because the illustrations live in `assets/`.

## Added in this research edition
- Source-linked historical case studies: early local meme pages, “Khela Hobe”, Earki's 2019 meme calendar, the 2021 “কেন? কেন? কেন?” reaction, July 2024 protest memes, and 14AGAIN.
- Recent reported trends from September–October 2026: AI retro photos, Unseen Bangladesh map-sharing, and the Baper Rasta browser game.
- A context-first case study on the “Aj Keno Mon Udashi Hoye” Reels/audio trend, with emphasis on context collapse and cyberbullying rather than re-sharing a private person's video.
- Original editorial SVG illustrations. These are interpretations, not copies of the original viral image/meme and do not claim to be the original posts.
- Story search/filter, story detail, source links, share links, and local-only story builder.

## Research & rights note
Trend labels are based on dated journalism, not live access to Meta's private trend dashboards or complete platform analytics. A report that a trend was viral is not the same as a verified engagement ranking. Original meme images and private social posts have not been re-hosted; each research story links to the publication that documents it. Please check terms/permissions before reproducing third-party images.

## Local storage
No backend, login, paid API, or database is required. User-created stories stay in the browser's local storage and do not sync across devices. First-time opening of this edition automatically includes the new curated story set while preserving user-created stories from the previous local version.
